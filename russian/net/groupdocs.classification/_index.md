Пространство имён GroupDocs.Classification предоставляет классы для классификации текстов и документов. Основные классы в пространстве имён: Classifier является точкой входа для классификации. Taxonomy представляет все поддерживаемые таксономии. PrecisionRecallBalance представляет все поддерживаемые балансы точности/полноты для таксономии Documents.
